# MapleUp

MapleUp 是一個以「**現在最該強化哪一隻打王分身？**」為核心問題設計的 MapleStory / 新楓之谷角色管理工具。

## MVP 核心

- 🔥 強化總覽：先排除已達停手條件的角色，再顯示待強化與待測角色
- 👤 角色管理
  - 📊 總覽
  - 📋 能力面板
  - 🛡️ 裝備分析
  - 📈 戰力紀錄
- 💰 結晶收入
- ⚙️ 設定

## 目前規則

- 指定 Boss 通關時間 **嚴格小於 30:00** → `停手`
- 剛好 `30:00` 不算達標
- 沒有有效通關時間 → `待測`
- 超過或等於 30:00 → `待強化`
- `目前戰力` 與 `歷史最高戰力` 分開保存
- 所有抓取戰力可形成歷史曲線；最高戰力只在新值更高時更新

## 第一版技術策略

目前原型是無建置步驟的靜態 Web App：

- HTML / CSS / Vanilla JavaScript
- localStorage
- 手機友善
- 可直接用瀏覽器開啟

這是為了先驗證資訊架構與操作流程。

正式版預計：
- 前端：React + TypeScript
- 後端：Cloudflare Worker 或同等 serverless
- 資料庫：Supabase/Postgres
- NEXON Open API：由後端安全呼叫，不把 API Key 暴露在前端
- 排程：自動同步角色資料
- 歷史：保存戰力快照與最高戰力

## 執行原型

直接開啟 `index.html` 即可。

若瀏覽器限制本機資源，可在資料夾內執行：

```bash
python -m http.server 8080
```

然後開啟 `http://localhost:8080`。
