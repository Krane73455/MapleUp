# MapleUp

MapleUp 是一個以「**現在最該強化哪一隻打王分身？**」為核心問題設計的 MapleStory / 新楓之谷角色管理工具。

## MVP 核心

- 🔥 強化總覽：先排除已達停手條件的角色，再顯示待強化與待測角色
- 👤 角色管理
  - 📊 總覽
  - 📋 能力面板
  - 🛡️ 裝備分析
  - 📈 戰力紀錄
  - 篩選、搜尋、封存、編輯與刪除；職業依劍士、法師、弓箭手、盜賊、海盜分類選擇
- 💰 結晶收入
  - 左側選角色，右側直接點 Boss 難度；再點一次取消
  - 自動帶入參考結晶價格，依 1–6 人隊伍計算個人金額
  - 週王每角色 12、全角色 90 的新增上限
  - 週王／月王切換及通關勾選；黑魔法師難度整合於同一列
- ⚙️ 設定
  - JSON 備份、預覽還原與操作前復原備份
  - NEXON Open API Key 管理與全部角色同步
- 🔄 NEXON Open API：輸入角色名稱即可建立角色，或同步既有角色的職業、等級、戰力、能力值及目前裝備

## 目前規則

- 指定 Boss 通關時間 **嚴格小於 30:00** → `停手`
- 剛好 `30:00` 不算達標
- 沒有有效通關時間 → `待測`
- 超過或等於 30:00 → `待強化`
- `目前戰力` 與 `歷史最高戰力` 分開保存
- 所有抓取戰力可形成歷史曲線；最高戰力只在新值更高時更新
- 修改目前戰力時自動新增歷史紀錄；只改名稱、Boss 或備註不會重複新增
- 目前戰力僅由 NEXON API 同步，不提供手動修改
- 等級僅由 NEXON API 同步，不提供手動修改

## 第一版技術策略

目前原型是無建置步驟的靜態 Web App：

- HTML / CSS / Vanilla JavaScript
- localStorage
- 手機友善
- 可直接用瀏覽器開啟

這是為了先驗證資訊架構與操作流程。

後續可擴充：
- 前端：React + TypeScript
- 後端：Cloudflare Worker 或同等 serverless
- 資料庫：Supabase/Postgres
- 排程：自動同步角色資料
- 歷史：保存戰力快照與最高戰力

## 執行原型

直接開啟 `index.html` 即可。

若瀏覽器限制本機資源，可在資料夾內執行：

```bash
python -m http.server 8080
```

然後開啟 `http://localhost:8080`。

## 本機資料與備份

資料只保存在目前瀏覽器的 `localStorage`，不會隨 GitHub 帳號跨裝置同步。請在「設定 → 本機資料」定期匯出 JSON。

NEXON API Key 另外保存在目前瀏覽器，不會寫入 repository 或 JSON 備份。到「設定」貼上 Key 後，按「新增角色」並輸入角色名稱即可從 API 建立完整角色；也可在角色頁逐隻同步，或一次同步全部角色。同步會保留 Boss 設定、備註、手動能力值、手動裝備分析、結晶與既有戰力歷史。

- 匯入前會顯示角色、戰力與結晶紀錄數量，確認後才取代目前資料。
- 匯入、刪除角色或重置示範資料前，會保存一份「上次操作前備份」。
- 支援 MapleUp v1 備份格式及 v0.1 的原始 JSON 資料。
- 刪除角色會保留既有結晶收入紀錄。
- 舊版角色級結晶合計與手動金額會保留，不會被自動拆分或改價。
- 封存角色會保留歷史、NEXON 快照及結晶紀錄，並退出目前角色與同步名單。
